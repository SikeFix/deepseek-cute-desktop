DeepSeek Cute Desktop 1.7.0 安装指引
====================================

一、macOS(Apple Silicon / M2 及以上)
------------------------------------
1. 双击 DeepSeek-M2-1.7.0.dmg 挂载镜像。
2. 将 DeepSeek.app 拖入 Applications 文件夹。
3. 首次打开: 若提示"无法验证开发者", 请在
   系统设置 → 隐私与安全性 中点击"仍要打开", 或在终端执行:
   xattr -dr com.apple.quarantine /Applications/DeepSeek.app
4. 应用内置本地 Node 运行时与模型服务, 无需额外安装环境。

二、Windows 10 / 11 (x64)
-------------------------
1. 下载 DeepSeek-Cute-Windows-x64-Setup-1.7.0.exe 并双击安装。
2. 安装为单点击 NSIS 安装器, 跟随提示完成即可; 安装完成后自动启动。
3. 首次启动会在后台拉起本地服务(端口 3080), 顶部状态胶囊由
   "启动中"(黄)变为"在线"(绿)后即可使用。
4. 若公司网络/杀毒软件拦截, 请允许 node.exe 联网与本地通信。

三、获取 API 密钥
-----------------
应用默认使用 ssnh.top 的千问模型通道(https://www.ssnh.top/v1, 支持图片输入)。
点击顶部模型胶囊 → "模型服务设置", 或访问 https://www.ssnh.top 注册登录后
获取 API 密钥并填入。密钥仅保存在本机:
- macOS: 系统钥匙串
- Windows: DPAPI 加密存储
不会上传到任何服务器, 也不会写入日志。

四、1.7.0 新功能
----------------
- 多主题: 官方样式 / 正太主题 / 暗夜极光 / 奶油纸感 / 深海鲸语, 顶部或菜单栏一键切换。
- 主题工坊: 自定义颜色、壁纸、吉祥物形象与欢迎文案, 保存为个人主题;
  主题保存在用户目录, 应用更新不会丢失。
- Token 使用统计: 累计/峰值 Token、最长聊天时长、连续天数、每日/每周/累计
  Token 活动热图、近 7 日 / 近 30 日明细、每日趋势图与模型用量。
- Windows 顶栏重做: 可拖动、服务状态指示、主题与模型胶囊、窗口控制。
- macOS 顶栏可像普通应用一样拖动移动窗口。
- 稳定性: 本地服务不再自动抢占系统浏览器; 异常退出自动退避重启;
  运行时内存限制; 安装包瘦身, 安装与运行更流畅。

五、更新说明
------------
已安装 1.6.0 的用户直接覆盖安装 1.7.0 即可, 自定义主题与 API 密钥均保留。
Windows 客户端内置自动更新(GitHub Releases); macOS 请重新下载安装新 DMG。

六、校验文件完整性
------------------
每个资产均附带 .sha256 文件, 下载后可校验:
- macOS:   shasum -a 256 -c DeepSeek-M2-1.7.0.dmg.sha256
- Windows: certutil -hashfile DeepSeek-Cute-Windows-x64-Setup-1.7.0.exe SHA256
